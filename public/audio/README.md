# Фоновая музыка

Плеер сначала ищет файл:

```text
public/audio/rokugan-ambient.mp3
```

Чтобы заменить музыку для всех игроков, положите новый MP3 по этому пути и выполните обычный деплой.
Файл не добавлен в Git намеренно: перед публикацией нужно самостоятельно проверить лицензию трека.

Если файл отсутствует, кнопка `♫+` открывает выбор локального аудиофайла. Такой файл играет только в текущей вкладке и никуда не загружается.
